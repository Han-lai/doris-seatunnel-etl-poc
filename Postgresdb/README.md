# PostgreSQL TPC-H Setup

This directory contains scripts for loading TPC-H benchmark data into PostgreSQL.

## Contents

- `tpch2postgresdb.py` - Python script to load TPC-H data into PostgreSQL
- `postgres/` - PostgreSQL related files
- `postgres_venv/` - Python virtual environment (not included in repository)

## Usage

1. Set up PostgreSQL connection parameters in `tpch2postgresdb.py`
2. Ensure TPC-H data files are available
3. Run the script to load data

Refer to the main project README.md for detailed instructions.
