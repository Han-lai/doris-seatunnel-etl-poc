# MFG_DP - Doris Configuration

This directory contains Apache Doris deployment configurations and related data pipeline setups.

## Contents

- `doris/` - Doris FE/BE Docker deployment configurations
- `postgres/` - PostgreSQL Docker environment with TPC-H schema
- `seatunnel/` - SeaTunnel ETL pipeline configuration files
- `kafka_RoutineLoad/` - Kafka Routine Load related configurations
